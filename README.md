# A/B-тест нового алгоритма рекомендаций

Анализ A/B-эксперимента для развлекательного приложения с бесконечной лентой.

Цель проекта — проверить, увеличивает ли новый алгоритм рекомендаций вовлечённость пользователей. Основная метрика эксперимента — **доля первых сессий, в которых пользователь просмотрел 4 и более страниц**.

## Что сделано

- проведён EDA исторических данных;
- изучена динамика регистраций и поведения пользователей;
- рассчитан необходимый размер выборки;
- оценена ожидаемая длительность A/B-теста;
- проверен баланс групп A и B;
- проверено отсутствие пересечений пользователей между группами;
- сравнены распределения по устройствам и регионам;
- рассчитана ключевая метрика;
- проведён односторонний z-тест для двух долей;
- сформулирован продуктовый вывод.

## Ключевые результаты

Планирование эксперимента:

- уровень значимости `α = 0.05`;
- мощность теста `80%`;
- MDE — `3 п.п.`;
- необходимый размер выборки — около **3 761 пользователя на группу**.

Фактический эксперимент:

- период: **14 октября — 2 ноября 2025 года**;
- длительность: **20 дней**;
- всего пользователей: **30 579**;
- группа A: **15 163** пользователя;
- группа B: **15 416** пользователей.

Основная метрика:

| Группа | Доля успешных первых сессий |
|---|---:|
| A | 31.57% |
| B | 31.47% |

Разница B − A составила **−0.11 п.п.**  
Относительное изменение — около **−0.33%**.

Односторонний z-тест дал `p-value = 0.578352`, что значительно выше уровня значимости `0.05`.

**Вывод:** статистически значимого роста ключевой метрики не обнаружено. По результатам эксперимента новый алгоритм рекомендаций не показал преимущества перед текущим вариантом, поэтому оснований для его полной раскатки по этой метрике нет.

## Данные

В проекте используются три набора данных:

- `sessions_project_history.csv` — исторические данные;
- `sessions_project_test_part.csv` — данные первого дня эксперимента;
- `sessions_project_test.csv` — данные полного A/B-теста.

Notebook загружает данные напрямую из публичного хранилища Яндекс Практикума, поэтому отдельная папка `data/` для запуска не требуется.
